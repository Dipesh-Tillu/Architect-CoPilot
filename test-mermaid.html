🔧 Manual Mermaid Code Test

You can also test by providing raw Mermaid code. The diagrams will now render as actual visual diagrams using Mermaid.js:

Example Mermaid Code:

graph TD
    A[Start] --> B{Is it working?}
    B -->|Yes| C[Great!]
    B -->|No| D[Debug]
    D --> B
    C --> E[End]

Sequence Diagram Example:

sequenceDiagram
    participant U as User
    participant F as Frontend
    participant B as Backend
    
    U->>F: Enter credentials
    F->>B: Send login request
    B->>B: Validate credentials
    B->>F: Return token
    F->>U: Show success message

Class Diagram Example:

classDiagram
    class User {
        +String name
        +String email
        +login()
        +logout()
    }
    class Admin {
        +String role
        +manageUsers()
    }
    User <|-- Admin

🐛 Troubleshooting

If diagrams aren't working:

  1. Check browser console for errors
  2. Verify the extension is loaded and active
  3. Try reloading the page and extension
  4. Check that the Mermaid tool is properly integrated
